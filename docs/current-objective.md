# MINING 当前完整目标

用户于本会话确认：**从国内公开社区和评论中，找值得开发的产品或功能机会。** 用户负责必要的登录/验证码，MINING负责登录后的自动采集、可追溯入库、候选分析与决策依据。

## 实际完成条件

1. 先有一个国内平台可以在MINING内输入关键词/链接、使用用户已登录会话自动取得真实正文和限定评论；连接失败不另开登录窗口。
2. 用户可以预览、选择导入；原文、来源、采集时间与覆盖边界保留，重复导入不重复入库，快照可回读。
3. 候选区分具体困难、已有方案、尚存缺口和系统设想；不把产品推广或正面功能描述直接当新需求，证据不足时允许0候选。
4. 用户能据原话与替代方案判断继续了解、做原型或放弃，并知道下一步要验证什么。

## 当前进度与已完成里程碑（2026-11-16 更新）

- **已完成并真实验收（D4 + D5）**：
