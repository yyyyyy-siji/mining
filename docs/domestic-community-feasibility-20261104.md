# 国内社区采集可行性与当前实现状态

核实日期：2026-11-04。范围：当前源代码、公开官方文档、第三方采集项目的原始说明。**本轮未开发新连接器，也未登录这些平台或调用需要密钥的接口，不能写成实网采集验收通过。**

## 结论

MINING 可以以国内社区为主要数据来源，已有原文导入、来源校验和本批候选分析可复用。缺口主要在真实采集层。现有网页自动采集仅包含 HN 与 V2EX；平台选择列表并不等于已实现抓取。

## 代码真实状态

| 平台 | 当前情况 |
| --- | --- |
| V2EX | O1/O2已真实采集验证，限问与答/奇思妙想当前订阅流帖子，无全历史/评论覆盖 |
| 知乎 | 支持原文+URL导入；没有真实联网采集器 |
| 小红书、微博、B站、抖音 | 旧Connector依赖模拟MediaCrawlerClient，未连接真实外部采集服务；不能算已经接通 |
| 贴吧、掘金、公众号 | 支持来源规则与材料导入；未发现真实联网采集器。输入已有OCR文本不代表系统执行了OCR |
| 博客园 | 有调用方传入JSON或URL+正文的转换器，不主动请求API |

关键证据：

- `signal_miner/routes/connectors.py` 的 `CommunityPreviewRequest.source` 仅允许 `hn|v2ex`，worker仅有这两条联网采集分支。
- `signal_miner/connectors/media_crawler_client.py:25–42` 明确为mock，生成 `mock_*`、模拟正文和模拟URL，无HTTP读取；cookie校验也为模拟逻辑。
- `signal_miner/connectors/platforms/bilibili_adapter.py` 和 `cnblogs_adapter.py` 为已有数据转换器，不获取真实网页/评论。

## 最新外部入口核对

### 知乎：存在官方数据平台，适合优先接入

已在浏览器实际阅读官方网页，而非仅依赖搜索摘要：

- [知乎搜索API](https://developer.zhihu.com/docs?key=zhihu_search)：返回问题、回答或文章结果；需要非空关键词，单次最多10条，当前 `HasMore=false`。
- 返回字段包含标题、`ContentText`（文档明确为**摘要**）、带溯源参数的原始链接、赞同/评论数量；可选 `CommentInfoList` 为精选评论，不是全量评论。
- [鉴权文档](https://developer.zhihu.com/docs?key=authorization)：需账户中的Access Secret，使用Bearer鉴权及请求时间戳。未获取用户密钥，未验证实际可用额度。

实施时，摘要应作为发现线索，不能冒充完整原文；完整正文和全评论的获取能力需另行核实。保留真实链接，精选评论若没有作者/时间/独立ID，应明确未知，不补造元数据。

### B站：官方开放能力与任意视频评论需区分

实际阅读 [开放平台](https://open.bilibili.com/doc) 及 [获取用户数据](https://open.bilibili.com/doc/4/90936ab5-7c06-e24f-2ad0-0fd6e10c7386)：所查接口明确需要申请权限与用户授权，内容是用户维度数据。不能据此推断存在面向任意视频的通用评论读取权限。

指定公开视频的可见评论可作为浏览器辅助采集的验证目标；当前项目未实现、未实测，不能承诺无需登录或长期稳定。

### 小红书、微博、贴吧等：有技术实现先例，仍需逐平台验证

[MediaCrawler原项目](https://github.com/NanmiCoder/MediaCrawler) 列出这些平台及B站/知乎的关键词搜索、指定帖子与评论能力，采用浏览器登录态。这是技术可行性的参考，不是MINING已经接入的证据，也不是平台官方授权或长期可用性保证。

该仓库的 [LICENSE](https://github.com/NanmiCoder/MediaCrawler/blob/main/LICENSE) 限定非商业学习用途，商业使用要求版权所有者书面同意。不能直接当作无条件可商用的工程依赖；具体落地应选择适用的官方权限、授权数据来源或用户浏览器可见内容采集方案。

## 建议的实施顺序（基于以上证据的判断）

1. 优先接知乎官方搜索：最清晰的接口边界，先完成真实关键词检索→摘要/精选评论预览→原文核对。
2. 小红书或B站做指定链接、限量可见评论采集试验：先验证用户现有账号环境下的实际可用性，再考虑关键词发现。
3. 微博/贴吧在前两项稳定后按真实反馈价值选一个接入，不一次铺开全部平台。

HN可以保留为可选来源，不作为国内主流程依赖。国内运行的网络可达性仍需在用户实际网络、账号和授权条件下实测，本轮不凭时区或工具网络推断所有境内线路都稳定可用。
